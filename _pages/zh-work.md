Yong 的工作经历主要分为三条线：工业机器人现场部署、软硬件产品建设，以及 Physical AI 相关产品定义。下面列出的项目不是完整清单，而是最能说明其机器人、工业技术和产品经验的部分。

## 职业主线

- **机器人现场经验**：部署、调试、故障排查、稼动率、安全、客户验收和售后支持。
- **Physical AI 产品定义**：人形机器人路线图、数据采集平台、老人陪伴机器人概念和真实使用场景。
- **工业到云基础设施**：工业路由器、PLC / 机器人连接、WireGuard、SaaS、AWS、App、Docker 和 OpenWrt。
- **创业与商业化**：从产品想法到用户、试点、付费客户、全球用户和公司退出。
- **跨境执行**：中国、德国、美国、墨西哥及亚欧北美工业客户与合作网络。

## Physical AI 产品领导力
{: #physical-ai-product-leadership }

Yong 的 Physical AI 工作建立在多年机器人现场经验之上。重点不是简单判断机器人能否完成动作，而是判断它先做什么、在哪些场景中使用、需要什么数据、哪些能力适合放在端侧，以及产品能否被部署和维护。

### OmniEdge Humanoid Foundry
{: #omniedge-humanoid-foundry }

![OmniEdge Humanoid Foundry 可配置人形机器人](/images/humanoid-foundry.png)

创建可配置的人形机器人产品启动方案，将机器人本体、集成控制系统、边界清晰的 AI 演示和工业设计整合为一条由单一团队负责的交付路径。客户可以从完整的双足机器人开始，并按需加入面向发布的 AI 演示或品牌化外观设计，无需从零重建平台。

项目采用付费架构冲刺、明确的验收标准、完整的配置记录和可验证的演示证据，帮助团队将人形机器人研发转化为可信的 Alpha 产品发布里程碑。

[访问 OmniEdge Humanoid Foundry](https://humanoid.omniedge.io/zh/){: .btn}

## 全球汽车机器人现场部署

![Industrial robotics system](/images/robotics-field-deployment.jpg)

汽车机器人项目要求高，涉及安全、节拍、质量、稼动率、客户验收、供应商协同、维护和生产排期。这些经验形成了 Yong 对机器人项目的基本判断：原型能动不等于系统能交付。

## 工业到云基础设施
{: #industrial-to-cloud-infrastructure }

![Jaybox industrial router](/images/jieqi-jaybox.jpg)

在 Physical AI 成为常见说法之前，Yong 已经在处理机器人和工业设备团队面临的基础设施问题：远程访问、安全连接、诊断、分布式设备管理和工业服务流程。

### JIEQI / Jaybox 工业 IoT
{: #jieqi-jaybox-industrial-iot }

JIEQI EdgeComputing 与 Jaybox 结合工业路由器、安全远程网络、云服务和原生应用。系统基于 WireGuard 连接，支持 PLC、机器人、工业视觉和生产设备的远程诊断、服务和编程。

### OmniEdge P2P Mesh VPN
{: #omniedge-p2p-mesh-vpn }

![OmniEdge platform](/images/omniedge-platform.png)

设计并发布 OmniEdge，一个开源 P2P Mesh VPN 与边缘网络 SaaS。平台覆盖 Linux、Windows、macOS、iOS、Android、Docker、Synology、OpenWrt 和 GitHub Actions 等环境。

**结果：** 覆盖 26 个国家的 7K+ 用户，并完成战略退出。
